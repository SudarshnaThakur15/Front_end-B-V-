A responsive landing page for a digital marketing agency, built from a design mockup with reusable React components.

## Sections

- Navigation and hero header
- Brand logo strip
- **Services** card grid
- **"Our Working Process"**: step-by-step process blocks
- **Testimonials carousel**
- Footer with contact details and a newsletter signup

## Tech Stack

React · Vite · Tailwind CSS · React Bootstrap · React Router · Lucide icons

## Run Locally

```bash
npm install
npm run dev
```
